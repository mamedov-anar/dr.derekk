# Dr.Derek

Персональный сайт Дерека Чрагяна, врача-дерматолога и косметолога.

## Основной проект

Единственный актуальный источник проекта — [mamedov-anar/dr.derekk](https://github.com/mamedov-anar/dr.derekk).
Все дальнейшие изменения выполняются в этом репозитории. Отдельные локальные версии сайта больше не используются.

Готовый статический сайт находится в корне репозитория. Установка зависимостей и сборка не требуются.

## Структура

- `index.html` — главная страница.
- `about/`, `contact/`, `treatments/`, `legal/`, `404/` — действующие страницы сайта.
- `services-preview/` — отдельная тестовая страница новой структуры услуг.
- `assets/` — локально размещённые стили, модули, фотографии, шрифты и данные.
- `site-config.js` — публичный адрес сайта и настройки доставки формы.
- [`PAGES.md`](PAGES.md) — справочник всех основных, внутренних, тестовых, служебных и удалённых страниц с адресами и назначением.
- `pages.json` — список 20 исходных маршрутов; тестовые страницы учитываются в `PAGES.md`.
- `asset-manifest.json`, `SHA256SUMS.txt` — реестр файлов и контрольные суммы.
- `docs/QA-2026-10-25.md` — результаты проверки перед переносом.
- `AGENTS.md` — правила дальнейшей работы с проектом.

## Справочник страниц

Полный перечень страниц и их статусы находятся в [`PAGES.md`](PAGES.md).
Действующий каталог — [`/treatments/`](https://mamedov-anar.github.io/dr.derekk/treatments/), отдельная тестовая версия — [`/services-preview/`](https://mamedov-anar.github.io/dr.derekk/services-preview/).
Справочник обновляется при добавлении, удалении, переименовании страницы или изменении её роли.

## Публикация

Публичный сайт: [Dr.Derek](https://mamedov-anar.github.io/dr.derekk/).

Источник GitHub Pages — ветка `main`, корень `/`. Файл `.nojekyll` сохраняется в корне.
Изменения опубликованной версии вносятся через этот репозиторий.

## Типографика

Единая гарнитура сайта по умолчанию — **Source Sans 3** для всех языков, включая кириллицу и латиницу.
Общее правило задано в `assets/portable.css` и действует для заголовков, текста, навигации, кнопок и полей форм, в том числе после загрузки клиентского кода.
Файлы Source Sans 3 в формате WOFF2 размещены в `assets/fonts/source-sans-3/` и загружаются с самого сайта. Подключены обычное и курсивное вариативные начертания с насыщенностью 200–900. Размеры текста и адаптивные правила сохраняются.
Источник — [официальный репозиторий Adobe](https://github.com/adobe-fonts/source-sans/tree/87b37a2daaed80fcb8e8ccb0085c4d72ddade12e), файлы шрифтов сохранены без изменений. Лицензия SIL OFL 1.1: `assets/fonts/source-sans-3/LICENSE.md`.

## Запись и форма

Запись: **+7 918 070 1493**. Кнопки записи открывают звонок.
Форма не отправляет сообщения, пока не настроен собственный HTTPS `formEndpoint`.
Адрес сайта задаётся в `siteUrl` в `site-config.js`.
