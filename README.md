# Dr.Derek

Персональный сайт Дерека Чрагяна, врача-дерматолога и косметолога.

## Основной проект

Единственный актуальный источник проекта — [mamedov-anar/dr.derekk](https://github.com/mamedov-anar/dr.derekk).
Все дальнейшие изменения выполняются в этом репозитории. Отдельные локальные версии сайта больше не используются.

Готовый статический сайт находится в корне репозитория. Установка зависимостей и сборка не требуются.

## Структура

- `index.html` — главная страница.
- `about/`, `contact/`, `treatments/`, `legal/`, `404/` — действующие страницы сайта.
- `services-preview/` — отдельная тестовая страница новой структуры услуг.
- `treatments_2/` — тестовая страница, созданная на основе копии каталога `/treatments/`.
- `assets/` — локально размещённые стили, модули, фотографии, шрифты и данные.
- `site-config.js` — публичный адрес сайта и настройки доставки формы.
- [`PAGES.md`](PAGES.md) — справочник всех основных, внутренних, тестовых, служебных и удалённых страниц с адресами и назначением.
- `pages.json` — список 40 маршрутов; тестовые страницы учитываются в `PAGES.md`.
- `asset-manifest.json`, `SHA256SUMS.txt` — реестр файлов и контрольные суммы.
- `docs/QA-2026-10-25.md` — результаты проверки перед переносом.
- `AGENTS.md` — правила дальнейшей работы с проектом.

## Справочник страниц

Действующий каталог — [`/treatments/`](https://mamedov-anar.github.io/dr.derekk/treatments/), отдельная тестовая версия — [`/services-preview/`](https://mamedov-anar.github.io/dr.derekk/services-preview/).

## Публикация

Публичный сайт: [Dr.Derek](https://mamedov-anar.github.io/dr.derekk/).

GitHub Actions публикует готовые файлы из корня `main` на GitHub Pages. Файл `.nojekyll` сохраняется в корне. Сайт работает в подпапке `/dr.derekk/`.

Процесс [Verify and deploy Pages](.github/workflows/pages.yml) проверяет все HTML-файлы будущей публикации, включая новые страницы. Если счётчик отсутствует, изменён или дублируется, проверка завершится ошибкой до загрузки артефакта в GitHub Pages. Проверка также выполняется в pull request к `main`.

### Как добавить или обновить страницу

1. Поместите готовый HTML в нужный каталог. Задайте корректный базовый путь при подключении общих ресурсов. При добавлении маршрута обновите [справочник страниц](PAGES.md).
2. Добавьте новые файлы в индекс Git через `git add`. Запустите из корня репозитория `python3 .github/pages/prepare.py`. Скрипт сам находит HTML, подставляет Яндекс Метрику **114682237** из [единого фрагмента](.github/pages/metrika.html.inc) сразу после `<body>` и пересчитывает `asset-manifest.json` и `SHA256SUMS.txt`. Повторный запуск даёт тот же результат.
3. Запустите `python3 .github/pages/prepare.py --check` и включите подготовленный HTML и оба реестра в коммит. В pull request дождитесь проверки перед слиянием с `main`.

Корневой `404.html` включает резервный пиксель для посетителей с отключённым JavaScript. При штатном перенаправлении просмотр регистрирует счётчик страницы `/404/`.

## Типографика

Единая гарнитура сайта по умолчанию — **Source Sans 3** для всех языков, включая кириллицу и латиницу.
Общее правило задано в `assets/portable.css` и действует для заголовков, текста, навигации, кнопок и полей форм, в том числе после загрузки клиентского кода.
Файлы Source Sans 3 в формате WOFF2 размещены в `assets/fonts/source-sans-3/` и загружаются с самого сайта. Подключены обычное и курсивное вариативные начертания с насыщенностью 200–900. Размеры текста и адаптивные правила сохраняются.
Источник — [официальный репозиторий Adobe](https://github.com/adobe-fonts/source-sans/tree/87b37a2daaed80fcb8e8ccb0085c4d72ddade12e), файлы шрифтов сохранены без изменений. Лицензия SIL OFL 1.1: `assets/fonts/source-sans-3/LICENSE.md`.

Логотип **Dr.Derek** и иконка **Dr.** используют **Adobe Source Sans 3, насыщенность 650**. SVG содержат контуры букв из официального вариативного файла, поэтому не зависят от системных шрифтов. Все размеры PNG, ICO и Apple Touch Icon получены из того же начертания; логотип в изображении предпросмотра ссылок также обновлён. Вариативная ось `wght` зафиксирована на 650; исходный файл шрифта: SHA-256 `5f16566f7a40d39b339ad26be151fa5a1ab1f0c2574c7a2e619765584a1acbd8`.

## Запись и форма

Кнопки «Записаться на консультацию» прокручивают текущую страницу до блока «Место приёма». На страницах без этого блока они открывают раздел «Контакты» сразу на блоке «Место приёма». В блоке можно позвонить по номеру **+7 918 070 1493**.

При добавлении кнопки записи укажите `href="contact/#appointment-location"` с учётом базового пути страницы и атрибут `data-consultation-link`. Общий скрипт переключает её на прокрутку внутри страницы, если блок «Место приёма» на ней есть.
Форма не отправляет сообщения, пока не настроен собственный HTTPS `formEndpoint`.
Адрес сайта задаётся в `siteUrl` в `site-config.js`.
