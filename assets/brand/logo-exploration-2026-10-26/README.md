# doctor Derekk — тёплая палитра

16 вариаций выбранной DD-монограммы с правым профилем лица. Палитра: основной коричневый #88482B, персиковый #F5E0D6, белый #FFFFFF и светлый #F9F0EC.

Надпись во всех вариантах точно `doctor Derekk`. Полные логотипы — квадратные PNG 2048 × 2048 px: `white/` на белом фоне и `transparent/` с прозрачностью. `marks/` содержит знаки без надписи. Это растровые концепции.

`review/` — изображения с вариантами и проверкой уменьшения. `palette.json` — цвета по ролям; `prompts.json` — промпты; `manifest.json` — варианты и шрифты; `QA.json` — проверки; `source/selected-logo.jpg` — пользовательский референс из предыдущей итерации.

Отрисовка создана ImageGen по референсу. При экспорте заливки приведены к точным HEX палитры с сохранением альфа-канала. Надпись добавлена детерминированно. В B11 правая D содержит персиковую заливку внутри просвета; в остальных вариантах просветы преимущественно открытые.

Комплект хранится в репозитории mamedov-anar/dr.derekk как набор файлов. ZIP содержит изображения и сопроводительные данные без веб-страниц и их стилей.
