# doctor Derekk — тёплая палитра

16 новых вариаций выбранной DD-монограммы с правым профилем лица. Основной цвет #88482B, персиковый #F5E0D6, белые страница и шапка #FFFFFF, фон блоков #F9F0EC.

Надпись во всех вариантах точно `doctor Derekk`. Полные логотипы — квадратные PNG 2048 × 2048 px: `white/` на белом фоне и `transparent/` с прозрачностью. `marks/` содержит знаки без надписи. Это растровые концепции.

`index.html` — страница сравнения; `review/` — квадратные листы и проверка уменьшения. `palette.json` — цвета по ролям; `prompts.json` — промпты; `manifest.json` — варианты и шрифты; `QA.json` — проверки; `source/selected-logo.jpg` — пользовательский референс из предыдущей итерации.

Новая отрисовка создана ImageGen по референсу. При экспорте заливки приведены к точным HEX палитры с сохранением альфа-канала. Надпись добавлена детерминированно. В B11 правая D содержит персиковую заливку внутри просвета; в остальных вариантах просветы преимущественно открытые.

Серия находится в каноническом репозитории mamedov-anar/dr.derekk и опубликована отдельным обзором на GitHub Pages.
