# dr.derekk — правила работы

- Единственный актуальный проект: https://github.com/mamedov-anar/dr.derekk.
- Вся дальнейшая работа выполняется с актуальными файлами этого репозитория. Независимые локальные версии, старые экспортные папки и локальные веб-серверы не используются.
- Перед изменениями прочитайте актуальные файлы и состояние ветки на GitHub. Используйте GitHub Pages или опубликованное удалённое превью для проверки интерфейса.
- Сайт статический и размещён в корне: `index.html`, страницы и `assets/`. Сборщик не нужен.
- Поддерживайте корректную работу при размещении в подпапке `/dr.derekk/` на GitHub Pages.
- Для брендовых правок проверяйте HTML, общие модули, данные, поисковые индексы, иконки и социальные метаданные; после загрузки клиентский код не должен восстанавливать старый текст.
- Сохраняйте согласованные тексты, фотографии врача, номер записи и медицинские сведения вне явно запрошенной правки. Новые медицинские утверждения, отзывы, цены и регалии не придумывайте.
- Реальная доставка формы отключена до настройки собственного HTTPS endpoint; не подключайте посторонние обработчики.
- Технические идентификаторы библиотек и лицензионные уведомления сохраняйте.
- Гарнитура сайта по умолчанию — Inter для всех языков. Единое правило находится в `assets/portable.css`; оно распространяется на заголовки, текст, кнопки, формы и их состояния после загрузки клиентского кода. Не меняйте размеры текста без отдельного запроса.
- При изменении файлов обновляйте `asset-manifest.json` и `SHA256SUMS.txt`.
